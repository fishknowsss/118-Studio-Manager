## 视觉取舍

- 保留现有页面结构、蓝色与青绿主色、状态色、项目时间轴、深色主题和彩蛋入口。
- 移除任务两侧、资料分区、项目、账号浮层、课表与短剧侧栏的装饰性粗边框和焦点侧光；使用浅色面、细边缘与状态文字。
- Solid Glass 采用实体面、边缘亮线和浮层厚度，直接适配现有 CSS，不引入 Tailwind 或替换组件框架。
- 首页任务标题优先，元数据移至次行；窄屏人员卡采用两列，移除空占位造成的长空白，技能区保留可读高度。
- 使用 taste v2.1.4 的应用界面流程；参考方向为 Editorial greeting，seed 为 1899728035。按本次保留布局的要求，沿用已有工作台与配色，不采用方向中的居中改版。
- 参考 Solid Glass 官方源码提交 `6e8903e494a15491ceda38fafea5056c95a74d44` 的材质原则，未复制其组件或样式文件。
- taste 浏览器检查覆盖 1440、768、390 像素，结果为 0 项失败、3 项提示。提示涉及密集辅助文字、固定月历网格和手机语句来源的 14 像素边距；已逐张复核截图，保留这些紧凑工作台取舍。密集日期和元信息继续使用 11—12 像素。
- 静态扫描中的演示占位域名属于公开仓库要求；彩蛋材质、日期补零、菜单勾选与来源分隔符按其真实用途保留。静态匹配结果与浏览器实测分别判断。
